# Dashboard-Data-Centers
# 🖥️ Dashboard Data Centers  Aplicação desktop em **Python + Tkinter** que exibe o crescimento de data centers ao longo dos anos. Mostra imagem ilustrativa, gráfico de linha (Matplotlib) com dados de 2021–2025 e status textual do setor.   Stack Python · Tkinter · Matplotlib · Pillow, Rodar bash pip install pillow matplotlib python dashboard.py
